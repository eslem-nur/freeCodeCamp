JavaScript Basics
Introduction Variables Functions Loops Objects
Introduction

JavaScript is a programming language used to make web pages interactive.

It runs in the browser and can update content dynamically.

alert("Hello, world!");
Variables

Variables are containers for storing data values.

Use let, const, or var to declare them.

  • let – block-scoped, reassignable.
  • const – block-scoped, not reassignable.
  • var – function-scoped, older style.
let name = "Alice";
Functions

Functions are reusable blocks of code.

Defined using the function keyword.

function greet(name) {
return "Hello, " + name;
}
Loops

Loops help run the same code multiple times.

The for loop is commonly used.

  • Initialize, condition, increment.
  • Executes until condition is false.
for (let i = 0; i < 3; i++) {
console.log(i);
}
Objects

Objects store key-value pairs.

Used to represent real-world entities.

const person = {
name: "Bob",
age: 30
};
  • Access properties with dot notation.
  • Can contain methods (functions).
